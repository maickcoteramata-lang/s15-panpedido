# PanPedido

## Descripción

PanPedido es un sistema desarrollado para gestionar los pedidos de una panadería local. Permite registrar productos, tomar pedidos con una hora de retiro y marcar los pedidos como entregados, facilitando la organización y atención a los clientes.
